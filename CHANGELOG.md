# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] — Foundation release

### Added

- Practitioner-oriented implementation guide for the NIST AI RMF functions: Govern, Map, Measure, and Manage.
- Practical start path for teams beginning from scratch, working with existing AI systems, or preparing for compliance-oriented reviews.
- NIST AI RMF gap-assessment template.
- Filled generic sample gap assessment.
- Mapping references for EU AI Act and ISO/IEC 42001 context.
- README guidance clarifying the relationship between this guide and adjacent repos such as `governance-playbook`, `release-governance`, `release-checklist`, and `regulated-ai`.

### Notes

This repository is a practitioner guide and is not affiliated with or endorsed by NIST. Users should refer to official NIST sources for authoritative wording.

### Next

- Add more evidence-package examples for common AI governance gaps.
- Add mappings from gap-assessment findings to concrete templates and tools across the broader repo ecosystem.
- Add examples for portfolio-level and single-system assessments.
